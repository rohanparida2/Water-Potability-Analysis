# Water Quality Analysis & Potability Assessment

> A comprehensive Exploratory Data Analysis project examining nine physicochemical parameters of 3,276 water samples to assess potability patterns and statistical differences between safe and unsafe drinking water.

---

## Overview

Access to safe drinking water is a fundamental human right. This project performs an in-depth EDA on the **Water Potability** dataset, exploring nine key water quality indicators, their distributions, outliers, inter-correlations, and statistical relationships with the potability label.

The project produces:
- A fully executed Jupyter Notebook with professional visualisations
- A polished academic report (DOCX) with embedded figures
- A clean `requirements.txt` for environment reproducibility

---

## Problem Statement

Given a set of physicochemical water quality measurements, identify:
1. Which parameters differ significantly between potable and non-potable water samples.
2. How each parameter is distributed across the dataset.
3. Whether any parameters are correlated with each other or with potability.
4. What data quality issues exist and how they should be handled.

---

## Objectives

- Load, inspect, and clean the water potability dataset
- Handle missing values using stratified median imputation
- Compute descriptive statistics for all nine parameters
- Visualise distributions and compare potable vs non-potable groups
- Detect and quantify outliers using the IQR method
- Assess pairwise Pearson correlations
- Apply the Mann-Whitney U test for statistical significance testing
- Summarise key findings with evidence-based conclusions

## Analysis Performed

## Key Findings

1. **Class imbalance:** 60.99% Non-Potable vs 39.01% Potable — relevant for any ML pipeline.
2. **No strong single predictor:** All feature–Potability correlations have |r| < 0.10.
3. **Statistically significant parameters (α = 0.05):** Chloramines, Solids (TDS), Organic Carbon.
4. **Potable water** has slightly higher mean Chloramines (7.169 vs 7.092 ppm) and Solids (22,384 vs 21,777 mg/L).
5. **Non-potable water** has marginally higher mean Organic Carbon (14.36 vs 14.16 ppm).
6. **pH, Hardness, Sulfate, Conductivity, Trihalomethanes, Turbidity** show no statistically significant group difference.
7. **Solids (TDS)** has the most outliers due to a right-skewed distribution.
8. Features are largely **uncorrelated with each other** — all nine carry independent information.
9. Statistical significance ≠ causation. Effect sizes are small throughout.

---

## Limitations

- High missing-value proportion in Sulfate (~24%) and ph (~15%) may introduce imputation bias.
- Dataset source and geographic context are not documented; findings may not generalise globally.
- The potability label is binary — it does not encode degree of (un)safety.
- Turbidity range in this dataset (1.45–6.74 NTU) far exceeds the WHO guideline (< 1 NTU), suggesting this may represent source or partially treated water.
- No temporal or spatial metadata available.
